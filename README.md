# Spotify Clone

A responsive Spotify-inspired music player built using HTML, CSS, and JavaScript.

## Features

- Responsive Spotify-style UI
- Playlist cards
- Search playlists
- Play and pause songs
- Previous and next song
- Music progress bar
- Volume control
- Song information display
- Active playlist indication
- Login modal
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
